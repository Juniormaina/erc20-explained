# Contributing

Thank you for your interest in contributing to **ERC20 Explained**.

The goal of this repository is to provide a clean, readable implementation of the ERC-20 standard that developers can learn from.

---

## Ways to Contribute

You can help by:

- Fixing bugs
- Improving documentation
- Writing additional tests
- Improving code readability
- Adding educational comments
- Suggesting improvements to explanations

---

## Development Setup

Clone the repository

```bash
git clone https://github.com/<your-username>/erc20-explained.git
```

Install dependencies

```bash
forge install
```

Build

```bash
forge build
```

Run tests

```bash
forge test
```

---

## Coding Guidelines

- Keep code simple.
- Prefer readability over clever optimizations.
- Follow Solidity style conventions.
- Write comments that explain *why*, not only *what*.
- Add tests for new functionality.

---

## Commit Messages

Examples

```
feat: implement transferFrom

fix: correct allowance update

docs: explain approve and allowance

test: add fuzz tests for transfers
```

---

## Pull Requests

Please ensure:

- Code compiles successfully.
- All tests pass.
- New features include tests.
- Documentation is updated if behavior changes.

---

## Reporting Issues

When opening an issue, include:

- Solidity version
- Foundry version
- Steps to reproduce
- Expected behavior
- Actual behavior

---

## Educational Focus

This repository prioritizes learning over production-ready implementations.

Contributions that improve explanations, diagrams, comments, and examples are especially welcome.

Thank you for contributing!
